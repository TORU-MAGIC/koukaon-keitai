効果音リモコン（iPhone向け）

Safariで使うインストール可能なWebアプリです。ゲームパッド入力、キーボード入力、画面タップに対応します。6つの効果音を同梱しています。

使い方
1. アプリ一式をHTTPSで配信できるWebサーバーへ置きます（PWAとオフライン保存にはHTTPSが必要です）。
2. iPhoneのSafariでURLを開き、「音を準備する」を押します。
3. iPhoneの設定 > Bluetooth でコントローラーを接続します。
4. 効果音の「ボタン登録」を押し、コントローラーのボタンを押します。
5. Safariの共有メニューから「ホーム画面に追加」を選ぶと、アプリのように起動できます。

注意
- コントローラーがiOSのゲームコントローラーとして認識される必要があります。機種・接続モードによってSafariに入力が届かない場合があります。
- iPhoneの音量ボタン、再生/一時停止ボタンなどはiOSが処理するため、アプリへ届かないことがあります。
- 使用中はSafariまたはホーム画面アプリを前面にしてください。iOSがバックグラウンドへ移すと入力検出が停止します。
- 効果音はiPhoneまたはiPhoneに接続したBluetoothスピーカーから再生します。
- キー割り当ては現在のSafariに保存されます。
